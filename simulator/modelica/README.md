# Modelica Workspace

Coloque aqui os modelos `.mo` usados para validação cruzada na Fase 3.

Sugestão mínima:
- um modelo CSTR equivalente ao cenário Python
- um script ou pacote capaz de expor variáveis comparáveis com `methane`, `biogas`, `pH`, `VFA` e `effluent COD`

O runner `python -m simulator.validation` detecta automaticamente arquivos `.mo` no workspace.
